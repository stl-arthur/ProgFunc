# ProgFunc
Este repositório tem como função armazenar publicamente os exercícios práticos e atividades realizadas
durante o percurso na matéria de Programação Funcional

### Importante
Este material é de caráter pessoal e somente para aprendizado, logo, o mesmo pode conter conteúdos não válidados
como códigos e respostas incompletas, resoluções não totalmente otimizadas, etc.
